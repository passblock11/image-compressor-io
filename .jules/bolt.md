## 2024-06-21 - [pyvips Migration for Fast Image Compression]
**Learning:** Migrating the image compression endpoint from Pillow to pyvips using `thumbnail_buffer` provides significant latency benefits (~65% faster). Using `thumbnail_buffer` utilizes shrink-on-load optimizations to avoid decoding the full image when resizing, which saves memory and CPU cycles. We also learn that checking file size synchronously with seek/tell before calling any library avoids redundant memory allocation, especially for massive or empty payloads.
**Action:** Use pyvips with `thumbnail_buffer` and lazy load headers via `new_from_buffer` for high-performance image compression services on large image datasets. Keep error handling robust by catching specific HTTPExceptions and pyvips.Error respectively.
