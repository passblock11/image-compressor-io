## 2026-10-13 - Fast Image Processing with pyvips and Sync Thread Pooling in FastAPI
**Learning:** High-resolution image processing with Pillow in async FastAPI handlers blocks the main asyncio event loop and executes up to 3-4x slower due to GIL/memory layout overhead. Switching to C-backed `pyvips` leverages demand-driven streaming, shrink-on-load decompression, and multi-threading (~3.3x speedup). Additionally, defining CPU-heavy endpoints as synchronous (`def` instead of `async def`) offloads execution to Starlette's thread pool, keeping the event loop responsive.
**Action:** When performing heavy image manipulation or file parsing in FastAPI, prefer C-backed streaming libraries like pyvips and define handlers synchronously (`def`) so Starlette worker threads handle the CPU workload.
